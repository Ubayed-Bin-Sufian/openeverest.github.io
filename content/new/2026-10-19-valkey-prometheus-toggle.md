The Valkey topology UI now includes a toggle for Prometheus monitoring, so you can enable or disable metrics collection for a Valkey cluster directly from the UI instead of editing manifests or running CLI commands.

The change keeps monitoring configuration next to the rest of the topology, where instance-wide settings are already managed.

To learn more, visit the [provider-valkey v0.1.9 release](https://github.com/openeverest/provider-valkey/releases/tag/v0.1.9).
